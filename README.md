#  Apricus TD

## This is Apricus TD, a tower defence game I made in Godot; the theme of the game is natural and comfy. There are many types of towers in it to defend the base and the enemies are even cooler

### Key features
* **Core Mechanic:** The game has a lot of animations the progress is rewarded, the tower moves in a unique way
* **Levels:** This game has 10 levels here as I want to publish on steam and playstore
* **Art:** I used the open-source platform krita for art
* **Music:** I used reaper for the music production
